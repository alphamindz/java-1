# Even or Odd Checker

A simple Java program that tells you if a number is even or odd.

## How it Works
1. The program asks you to type a number.
2. It uses the `%` (modulo) operator.
3. If the remainder is `0`, it is **Even**.
4. Otherwise, it is **Odd**.

## How to Run
1. Open your terminal or IDE.
2. Compile the file: `javac Main.java`
3. Run the program: `java Main`
